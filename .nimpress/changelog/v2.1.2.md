Deep links keep up with the reader again, and a roadmap sidebar shows what kind of work each row is.

## The hash follows the reader

Scrolling through a page updates the address bar to the heading in view, so copying the URL at any point shares the exact section on screen.

The page shell fills the viewport and scrolls inside its own column rather than scrolling the document, so the listener watching for scrolling never heard anything and the hash only changed when a reader clicked an entry in the right rail. It now listens where the scrolling actually happens.

This reaches every page that carries a table of contents: doc pages, changelog collections, roadmaps, and the API reference.

## Icons for issue types

A roadmap sidebar row carries a glyph for its kind rather than the kind spelled out. A milestone shows a flag, an epic shows a box, a feature shows a sparkle, and a bug shows an alert. The row reads as an icon followed by the issue title.
