A story stops being a bag of prop values and becomes a file that renders whatever it wants. An existing component library comes across in one command rather than page by page.

## Stories that run

A story file exports a definition through `vueStory` or `svelteStory`. A story carrying `props` seeds the workshop controls as before. A story carrying `render` returns a mount definition that the harness runs verbatim, so markup, fixture data, and composition all live in the story itself.

## Importing a library

`nimpress modules import` walks a component source tree, reads existing story files for their groups and named cases, seeds a schema per component from its types, and writes a default story for any component that has none.

1. `--match` narrows the walk to component names matching a pattern.

2. `--select` picks components interactively.

3. Re-running the import upserts and never clears authored content.

## Workshop screen

The workshop shell fills the viewport. The document itself does not scroll; the sidebar, the panels, and the component frame each scroll on their own.
