Guarded pages reach their modules through the address the publish step recorded.

## Published pairing

A guarded bundle resolves each file against the pairing written when the bundle was published, matching on the bundle and the file it ends with, and falls back to the bundle path only when no pairing exists. A guarded module whose stored address differs from its source path now loads instead of returning nothing.
