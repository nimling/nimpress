Two pieces of page chrome behave the way they read.

## Back to top

The button slides in once you are far enough down a page, and pressing it returns you to the top.

It watched for scrolling in a place the page never scrolls, so it stayed hidden no matter how far down a reader went, and pressing it moved nothing. It now watches the column the page actually scrolls in and returns that column to the top.

## Closing the subscribe dialog

The subscribe dialog closes from an icon button in its header rather than a small text label. Pressing escape still closes it.
