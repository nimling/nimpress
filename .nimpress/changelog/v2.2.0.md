Subscribing is reachable from the same place on every page that carries a feed.

## The control moves to the header

A page that enables a feed publishes its title, feed address, and whether email subscription is offered. The header reads that and renders the subscribe control beside search, the theme toggle, and the account menu. The dialog opens from there with the same options it always carried, the feed address and the email form when the page enables it.

The control leaves the changelog page heading, so the heading is now the title alone. On narrow viewports the control keeps its icon and drops its label to hold the header on one line.

Any page type can offer the control by publishing the same feed state, so it is no longer tied to the changelog renderer.
