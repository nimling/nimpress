A round of fixes to the OpenAPI reference, on a docs site and in a plain HTML page alike.

## Scrolling in a plain HTML page

A page that loads the browser bundle now scrolls the whole reference. The page header and the back to top button follow the window.

## One tooltip for every button

Every icon button on the reference shows the same tooltip on hover, drawn on whole pixels so the text stays sharp. Share and Clear in the try panel and the try dialog are icon buttons too, and the share tooltip reads `Copied` after a copy.

## Header

The version pill and the header buttons sit together on the right, the title takes the rest of the row, and the server table has rounded corners.

## Endpoint cards

Collapsed endpoint cards keep their gap, take only the room their path and summary need, and line up with the try panel beside them. The request body tabs sit closer to their heading, and enum values render at a whole pixel size.
