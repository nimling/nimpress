The default colors of both themes are now the palette of the Bookable portal.

## Brand

The default brand is indigo in both themes. Links, the active sidebar row, primary buttons, the highlighted code line and code annotations follow it. A site that sets `brand` in its configuration, or `--np-brand` in its own stylesheet, keeps its own color.

| Token | Light | Dark |
|-------|-------|------|
| `--np-brand` | `#6966DA` | `#6966DA` |
| `--np-brand-hover` | `#5755B8` | `#5755B8` |
| `--np-link` | `#373679` | `#BEC3F4` |
| `--np-text-on-brand` | `#FFFFFF` | `#FFFFFF` |
| `--np-tip` | `#FF7D33` | `#FF7D33` |

## Surfaces and text

The light theme moves from grey to a blue tinted ramp for backgrounds, text, borders and table rows. The dark theme moves to a neutral ramp on a `#171717` page, with lighter secondary and muted text.

| Token | Light | Dark |
|-------|-------|------|
| `--np-bg` | `#FFFFFF` | `#171717` |
| `--np-bg-surface` | `#F2F2F8` | `#1F1F1F` |
| `--np-bg-card` | `#FCFCFC` | `#1B1B1B` |
| `--np-bg-code-block` | `#18182A` | `#0A0A0A` |
| `--np-text-primary` | `#18182A` | `#FAFAFA` |
| `--np-text-muted` | `#4A4A60` | `#D4D4D4` |
| `--np-border` | `#CDCDE0` | `#262626` |

No token is renamed or removed. A site that overrides a token keeps its value.
