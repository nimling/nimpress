  title: Gated page content renders
  description: A gated page now shows its content for a viewer who holds its gate, instead of an empty page.

A gated page matched its route for a viewer holding the gate but rendered only the footer, because the page never received the gated content it belongs to. The router now hands each gated page its content, so the title, body and page type render as on any public page.
