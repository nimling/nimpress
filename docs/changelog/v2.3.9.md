Two new commands, so the cli can teach an agent to drive it and can complete itself in the terminal.

## The agent skill

`nimpress skill` ships the skill document that teaches a coding agent the whole cli surface: every command, every flag, where each folder is written, which packaged rule to read before authoring, and how to read a failure.

```sh
nimpress skill get
nimpress skill put
nimpress skill put --project
```

`get` prints the document. `put` installs it at `~/.claude/skills/nimpress/SKILL.md` so every project on the machine picks it up, and `--project` installs it at `.claude/skills/nimpress/SKILL.md` under the current directory instead. Either way the command prints the path it wrote.

The document ships inside the package, so `put` works the same from an installed copy as from a checkout.

## Shell completion

`nimpress completion` prints the completion script for `bash`, `zsh`, `fish`, or `powershell`, covering every command, every subcommand, and every flag.

```sh
nimpress completion zsh
nimpress completion --auto
nimpress completion --auto --skill
nimpress completion bash --auto
```

`--auto` detects the shell from `$SHELL` when none is named, writes a nimpress owned file under `~/.config/nimpress/completions`, and points the rc file at it from inside a managed block. Rerunning `--auto` refreshes the file and rewrites the block in place, so the rc never collects duplicates. fish is written to `~/.config/fish/completions/nimpress.fish` and needs no rc change.

`--skill` installs the agent skill globally in the same step, which is the one command a fresh machine needs.
