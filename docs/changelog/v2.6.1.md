`nimpress completion --auto` writes a `nimpress` shell function into its managed rc block, and into `~/.config/fish/functions/nimpress.fish` on fish. It runs the repo's pinned `node_modules/.bin/nimpress` when there is one and the latest release through `pnpm dlx` everywhere else, the same order the mcp server starts in. See [completion](/usage/completion).

```bash
pnpm dlx @nimtech/nimpress completion --auto --skill
```

Do not install nimpress with `pnpm add -g`. The global folder is one shared project, and a global Vite 5 from another tool can end up under the Svelte plugin, which then fails on start with `does not provide an export named 'defaultClientConditions'`. Remove such an install with `pnpm remove -g @nimtech/nimpress`.

The Svelte and Tailwind Vite plugins now load when a site is served or built. `view`, `export`, `guard`, `cache`, `mcp`, `completion`, `skill`, and `plugin` start without them.
