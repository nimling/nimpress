  title: Local pages win in view
  description: A preview shows the local pages in place of any site page they share a url with, so both read together before the real sync.
---

`nimpress view` no longer stops when one of your pages takes the url of a page the docs site already has. The site page is taken out of the preview clone, the output names it, and git brings it back on the next sync and the next run. The site repo is never written. See [view](/usage/view).

```text
nimpress view: the local pages replace docs/libraries/auth-middleware.md
```

The published site still refuses two pages on one url, so a replaced page is one the site repo retires before the real sync.
