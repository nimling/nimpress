Stories attach to the page they sit next to, and a sidebar group gains a look of its own.

## Stories sit beside their page

A story file placed next to a component page belongs to that page. There is no separate registry and no path to configure.

## Sidebar groups carry decoration

The `sidebar` block in frontmatter takes an `icon` and a `style` alongside its `name`, so a group row can carry a glyph and inline styling without changing any URL.

## Hash links

Following a link that carries a hash lands on the target heading rather than at the top of the page.
