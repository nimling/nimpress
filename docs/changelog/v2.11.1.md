The header of the OpenAPI reference takes less room and reads cleaner.

## Icon buttons

The download, collapse endpoints and collapse all controls are now icon buttons. Hovering one shows what it does, and the tooltip changes with its state. The tooltips also work in a plain HTML page that loads the browser bundle.

## Version pill

A spec whose version already starts with `v` shows it once, so `v1.0.0` no longer reads as `vv1.0.0`. The pill stays on one line.
