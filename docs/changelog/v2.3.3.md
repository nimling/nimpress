A site served from a subfolder keeps its pictures.

## Root relative images follow the base

The site logo, a hero logo and banner, a DBML page logo and banner, a page background, and a roadmap issue banner are all resolved against the `base` field now. Before this, a site deployed to a project page or any other subfolder asked the host for the path without the prefix and got nothing back.

Nothing changes for a site served from the root, and a full url or a relative path is left alone as before.

| Field | Where it is set |
|---|---|
| `logo` | The site config, shown in the header |
| `data.logo` and `data.banner` | A `hero` or `dbml` page |
| `background` | Any page, and a roadmap issue banner |

## A collection reads as one entry

A sidebar entry whose children are anchors into its own page, a changelog collection or an API reference with its tags, renders as a link with its children nested under it rather than as a section header. A folder of separate pages still reads as a section.
