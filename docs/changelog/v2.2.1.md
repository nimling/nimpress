Subscribing reads as part of the changelog rather than as a control floating above it.

## The control finds its anchor

The subscribe control sits beside the changelog title, and the email field opens directly instead of behind a second click. A reader who wants the feed address alone still copies it from the same dialog.

## A map of the feeds

Every build writes a map of the feeds it emitted beside them, naming each page, its title, and the entries it carries. A service that mails releases reads that map instead of guessing addresses. The root page is named `index` in the map, so a site whose changelog is its landing page appears there like any other.
