The API reference in a plain HTML page now closes with a footer.

## Footer

At the very bottom of the page sit the nimpress logo linking to the nimpress docs, the nimpress version the page runs on, the copyright and a made with love line. A nimpress site keeps its own footer. Every part of the new footer has a class to restyle it, listed in [Renderers styling](/styling/renderers).
