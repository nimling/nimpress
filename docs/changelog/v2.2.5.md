A reader subscribed to several changelogs can tell them apart.

## The list name travels

The page publishes the changelog name with the feed address, the dialog sends it when the reader subscribes, and the mailing service records it against the subscription. Guarded sites keep the pairing between a published artifact and the page it came from, so a gated changelog resolves its own feed.
