The API reference in a plain HTML page can now hand its reader a ready made Postman collection and a hurl archive, next to the specification itself.

## Download menu

`NimpressApi` takes two optional links, `postmanUrl` and `hurlUrl`. Each one that is set adds an entry to the download menu in the header, and the reader gets the file saved under the name of the specification. A link that is left out, `null` or `undefined` adds nothing, so a page that sets neither looks the way it did.

```html
<script>
  NimpressApi({
    url: 'spec/spec.json',
    target: '#api',
    postmanUrl: 'spec/postman',
    hurlUrl: 'spec/hurl'
  })
</script>
```

| Option | File the reader gets |
| --- | --- |
| `postmanUrl` | `<specification name>.postman_collection.json` |
| `hurlUrl` | `<specification name>.hurl.zip` |

Both are fetched by the browser when the reader picks the entry, and a relative link resolves against the page like `url` does.
