Commands from a page exist only while `nimpress dev` serves the site. A static build swaps `@nimtech/nimpress/commands` for a module where `commandsEnabled` is `false` and `postCommand` rejects, so the client and its route never reach the published pages.

## Guarding command ui

`commandsEnabled` is the new export to branch on. Put command buttons, panels, and calls behind `{#if commandsEnabled}` in Svelte, `v-if="commandsEnabled"` in Vue, or `if (commandsEnabled)` in plain JavaScript, and the build drops the guarded markup with everything it calls. The same holds for the component workshop build. See [Commands in a static build](/usage/dev#commands-in-a-static-build).
