A package can now ship its own Claude plugin and have nimpress install it, and the notes a component page shows beside its source are read from a file every agent recognises.

## A plugin a package ships

`nimpress plugin put <package>` installs the Claude plugin of a package installed in `node_modules`, the way `nimpress plugin put` installs nimpress's own. The package carries the plugin in a `plugin` folder with `.claude-plugin/plugin.json` and `.claude-plugin/marketplace.json`. The [plugin page](../usage/plugin) has the details.

| Command | What it does |
| --- | --- |
| `nimpress plugin put <package>` | Installs the plugin for the user, or updates it. |
| `nimpress plugin put <package> --project` | Installs it for the current project. |
| `nimpress plugin put <package> --check` | Installs nothing and fails when the installed plugin is missing or older than the package. |

## Agent notes on a component page

**breaking**: the notes rendered under a component page are now read from `AGENTS.md` in the component source folder, and from `AGENTS.md` beside the types of an installed package. A `CLAUDE.md` there is no longer read, so rename the file to keep the section.
