A ` ```d2 ` fence renders as a diagram, and so does a line holding only an image link to a `.d2` file, `![Platform overview](./platform.d2)`. nimpress reads D2 itself, so a page with a diagram downloads no diagram library, and the diagram follows the theme toggle. See [D2](/authoring/d2) and the [D2 diagrams](/examples/d2) example.

## What a diagram carries

Shapes, containers nested to any depth, chained connections with labels, every built in shape including `sql_table` and `class`, `direction`, grids, `near` titles, styles, arrowheads, `vars`, `classes`, and imports with `@file` and `...@file`.

## One diagram frame

Mermaid and D2 diagrams share one frame with the same pan, zoom, reset, and fullscreen controls, restyled through the `np-diagram-` classes. A D2 frame takes the proportions of its diagram.
