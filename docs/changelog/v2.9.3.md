A dropdown filter took its values from the `dropdowns` config block, so the menu showed even when no page declared one, and values from gated pages never reached a reader who had access. The menu now lists only the values pages declare. A value only gated pages carry arrives with the gated bundle, after sign in, and leaves with it. See [Dropdown filters](/sidebar#dropdown-filters).

## Glass theme

A rule in the glass theme was left open, so the browser dropped every rule after it, the dropdown trigger and panel among them. The rule is closed, and the dropdown trigger, the api Download, Collapse endpoints and Collapse all buttons and the download menu take the glass control and panel colors. Endpoint groups and the schemas group no longer paint a background of their own.
