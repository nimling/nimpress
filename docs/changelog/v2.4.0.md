The frontmatter grows two fields that shape how a page sits in the shell.

## Hide and status

One list hides any element of the page chrome, and one word marks the page in the sidebar.

`hide` takes a list of element names. `navigation` drops the sidebar column and the menu button, `toc` the right rail, `path` the breadcrumbs, `footer` the page footer line, and `tags` the tag row. A `hide` list in `defaultFrontmatter` merges with the page's own list instead of replacing it.

```yaml
hide: [navigation, toc]
```

**breaking** The boolean field that hid the right rail is gone. Every page that carried it writes `hide: [toc]` instead, and lint fails on a page that still carries the boolean.

`status` assigns the page a status shown in the navigation sidebar. The row carries a `np-sidebar-status` mark with the status label as its title, and `np-sidebar-status-<identifier>` beside it for coloring.

```yaml
status: new
```

| Identifier | Label |
|------------|-------|
| `new` | Recently added |
| `deprecated` | Deprecated |

The `status` field in `nimpress.config` maps further identifiers to labels, `status: { beta: 'Beta' }`.
