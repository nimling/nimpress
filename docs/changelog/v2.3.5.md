The class names were always documented as a public surface. Now they behave like one.

## Your rule wins

Everything the library ships is wrapped in a cascade layer:

```css
@layer nimpress {
  .np-header.svelte-e8nyzm { border-bottom: 1px solid var(--np-border); }
}
```

An unlayered rule beats a layered one whatever the specificity, so this is enough:

```css
.np-header {
  border-bottom: 2px solid var(--np-brand);
}
```

**Breaking** only in the sense that overrides get easier. A site that reached for `!important` to fight the scoped selectors can drop it, and a site that had given up on class overrides can stop duplicating the internal hash. Properties you do not name keep the value nimpress gave them.

Page stylesheets are injected unlayered, so a stylesheet named after a markdown file still wins over both.
