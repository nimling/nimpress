  title: Redirects change the address
  description: A page redirect and a gated page's gateDenied path now send the visitor to the target address through the route guard.
---

A page `redirect` and a `gateDenied` path now replace the address with the target, so the visitor lands on that page's own address instead of seeing it rendered at the old one. Gated routes are routed for every viewer behind a route guard that asks `checkAccess` from the auth functions, and `404` still shows the not found page at the requested address. The router is `sly-svelte-location-router` 3.3.6.
