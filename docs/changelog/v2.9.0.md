  title: Run cli commands from a page
  description: The dev server runs the cli commands the config allows for a page on localhost, and the page reads the result or listens to every line as it is written.
---

A page or a component calls a local cli through the dev server, the way a demo asks `claude` for an answer. `postCommand` from `@nimtech/nimpress/commands` resolves with the exit code, stdout, and stderr, writes `stdin` to the command when given, and with `onLine` hands over every line of stdout and stderr as it is written. It works the same from Vue, Svelte, or plain JavaScript.

`commands.allow` in the config decides what runs: `none` by default, `all`, or a list of entries such as `git log **` where every word after the command matches one argument and a trailing `**` matches the rest. A command outside the list is refused with a message that names it. The server answers only requests from localhost and is never part of a build. See [Run cli commands from a page](/usage/dev#run-cli-commands-from-a-page).
