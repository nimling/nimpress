  title: Commands answer in the component workshop
  description: A story in the component workshop runs cli commands like a page does, because the harness dev server now carries the command route.
---

The component workshop serves each design system from its own dev server, and that server had no command route, so a story calling `postCommand` was refused while a page could run the same command. The harness dev server now answers `/__nimpress/command` with the same `commands.allow` as the site.
