Every part of a site's look is now reachable from the config, from a whole theme down to a single component. See [Theming](/theming).

## Themes

`theme` picks the look of the site. `stock` is the default, applies whenever the field is absent, and matches what every site already shows. `glass` is optional. It lights the page with the brand color and lays frosted glass over the chrome, and the header stays clear at the top of a page and frosts over as content scrolls behind it. A path to a stylesheet loads it as the theme.

```json
{
  "theme": "glass"
}
```

## Switching themes

`themes` lists the themes a reader can pick from the palette menu in the header. `theme` stays the default and the reader's choice is remembered on their next visit.

```json
{
  "theme": "stock",
  "themes": ["stock", "glass"]
}
```

## Replacing components

`components` maps a component name to a Svelte file that renders in place of the stock one everywhere on the site. Thirty two components take part, from the header and sidebar to code blocks, cards, and the OpenAPI operation cards. Every stock component but `SidebarNode` is exported, so a replacement can wrap it.

```json
{
  "components": {
    "Footer": "./docs/theme/Footer.svelte"
  }
}
```

## New tokens

Overlays, shadows, the chrome around code blocks, and the controls in the lightbox each read a token now, and the brand color from the config can be overridden by a theme or a site stylesheet.

| Token | Covers |
|---|---|
| `--np-overlay`, `--np-overlay-soft` | Backdrops behind dialogs, search, and the mobile menu |
| `--np-shadow-popover`, `--np-shadow-dialog`, `--np-shadow-inset` | Menus, dialogs, and the component frame |
| `--np-code-bar-*`, `--np-code-gutter`, `--np-code-inset` | The bar, gutter, and chips around code |
| `--np-lightbox-control*`, `--np-shimmer` | Lightbox buttons and loading placeholders |

Code blocks now take their background from `--np-bg-code-block`.

## Header and announcement

The sidebar toggle sits beside the site title on wide screens and before it on small ones. Its icon shows whether the sidebar is open. The announcement now slides in as a notification in the bottom right corner and takes no space above the header. The dark mode toggle carries drawn icons.

**breaking** The classes `np-menu-line`, `np-menu-line-top`, `np-menu-line-mid`, `np-menu-line-bot`, and `np-announce-away` are gone. Style the toggle through `np-menu-icon`, `np-menu-pane`, `np-menu-fill`, and `np-menu-chevron`, and the announcement through `np-announce` and `np-announce-mark`.
