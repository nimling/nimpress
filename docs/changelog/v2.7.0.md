  title: Dropdown filters for the sidebar
  description: A page joins a sidebar filter through a dropdown block in its frontmatter, and the reader picks a value from the header or the sidebar footer.

Every page type takes an optional `dropdown` block in its frontmatter. Each key is a dropdown id, and `value` lists the choices the page shows under. `title` and `description` name the dropdown on any page, and the new `dropdowns` config block names it and orders its values for the whole site. A page without a value for a dropdown shows under every choice.

Each dropdown renders as a menu in the header on wide screens. At 1024 pixels and below it moves into the sidebar footer and opens upward as a panel. `All` is the default. Picking a value hides the pages that leave it out and the groups left empty, and the choice is remembered across visits.

A folder holding one page per value, each folder named after its value, is a variant folder. `Button/Vue/` and `Button/Svelte/` list as two rows under `Button` while everything is shown, and fold into a single `Button` row once the selection leaves one of them. The menu is `DropdownMenu` in `components`, and its classes are listed under [Shell](/styling/shell).
