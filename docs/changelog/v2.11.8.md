The plugin command is back to installing the nimpress plugin and nothing else. A package that ships a Claude plugin now carries its own installer.

## The plugin command

**breaking**: `nimpress plugin put <package>` and its `--check` flag are gone. `nimpress plugin put` and `nimpress plugin put --project` install the nimpress plugin as before, and the [plugin page](../usage/plugin) has the details.

The components library installs its plugin itself:

| Command | What it does |
| --- | --- |
| `pnpm dlx @nimling/components-nimtech plugin install` | Installs the plugin for the user, or updates it. |
| `pnpm dlx @nimling/components-nimtech plugin install --project` | Installs it for the current project. |
| `pnpm dlx @nimling/components-nimtech plugin install --check` | Installs nothing and fails when the installed plugin is missing or not the one the package carries. |

The notes under a component page are still read from `AGENTS.md`.
