  title: List the stories of a component
  description: nimpress modules stories lists a component's stories in every system with the harness route that renders each one alone.
---

`nimpress modules stories <Component>` lists the stories of a component in every configured system that carries it, with the harness route that renders one story alone, `/_components/<system>/<Component>/?story=<id>`. With no component it prints every component and its story count per system, `--system=` narrows it and `--json` prints the routes as json. It is also the `modules_stories` tool of the mcp server, so an agent finds a story and hands its route to a browser driver such as nimon without reading the generated harness.
