Two features live in two places, and now read that way in both.

## Database diagrams

The renderer and the page type are separate surfaces with separate contracts. [DBML pages](/page-types/dbml) is the full reference for `type: dbml`: the frontmatter, every header field, the band layout, the two buttons, and the source file the download hands over. [DBML](/extensions/dbml) covers what the fence renders, what the converter maps, how a column click navigates, and how to author the source.

Both forms render through the same component, so the second half of each page applies to the other.

## Component pages

[Component pages](/page-types/component) is the full reference for `type: component`: the frontmatter table, the one page per folder rule, grouping by folder or by declaration, the `## Usage` body convention, and what renders below the body without being authored. [Component modules](/modules) stays the reference for the system config, the harness composition, stories, the schema, the workshop screen, and the CLI.
