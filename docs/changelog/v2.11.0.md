A service can now show its OpenAPI spec in the nimpress reference from a plain HTML page, the same way it would load Swagger UI.

## Browser bundle

The package ships `dist/api.js` and `dist/api.css`. The script defines `NimpressApi`, which fetches a spec as JSON or YAML and renders the full reference into an element. See [the OpenAPI renderer](/page-types/openapi) for the page to copy.

```html
<link rel="stylesheet" href="https://unpkg.com/@nimtech/nimpress@2/dist/api.css">
<div id="api"></div>
<script src="https://unpkg.com/@nimtech/nimpress@2/dist/api.js"></script>
<script>
  NimpressApi({ url: 'spec/spec.json', target: '#api' })
</script>
```

## Styling

The stylesheet sits in the `nimpress` cascade layer, so a `<style>` in the page overrides any `--np-` token on `:root` and `html.dark` and any `np-` class without `!important`.
