Three fixes, one of them a page nobody could open.

## The root route never matched

**Breaking** for anyone who worked around it. A site with a `base` set could not render its own home page. The route was registered as `/my-site/` with a trailing slash, the router tested the visited path as `/my-site` without one, and the two never matched, so the page sat on the loading spinner forever. Every other route was fine because only the root produces a trailing slash.

Routes are now registered under both forms. A site served from the root was never affected.

If you added a redirect or a duplicate landing page to work around this, you can drop it.

## Changelog entries start closed

Every entry used to render expanded, so a collection with thirty releases opened as one enormous page. Entries now start collapsed and open on click. A direct hash such as `/changelog#v1.4.2` still expands that entry and scrolls to it.

## Images resolve under the base

The site logo, a hero logo or banner, a page background, and a roadmap issue banner written as root relative paths now resolve against the `base` field rather than asking the host for a path that does not exist.
