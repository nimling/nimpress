nimpress is an actively maintained and constantly improved project that serves a diverse user base with varying backgrounds and needs. In order to efficiently address the requirements of all our users, evaluate change requests, and fix bugs, we put in a lot of work.

## How you can contribute

### Report a bug

Something does not work the way the docs say. Write down what you saw, what you expected, and the smallest site that shows it. See [Report a bug](/community/report-a-bug).

### Report a docs issue

A page is wrong, unclear, or out of date. Every doc page carries an edit action at its top right that opens the file in the repository, so a fix is a pull request away.

### Request a change

A feature is missing or a behavior should change. Describe the use case first and the design second. See [Request a change](/community/request-a-change).

### Open a pull request

Code, docs, or tests. Follow [Pull requests](/community/pull-requests) so the change is easy to review and lands with its docs and its spec.

## Checklist

Before contributing, please make sure to:

1. Read the packaged rules under `node_modules/@nimtech/nimpress/.claude/rules/`; they say how pages, changelog entries, and components are written.

2. Search the changelog and the docs for the behavior, so a request does not ask for what exists.

3. Reproduce a bug with the latest release.
