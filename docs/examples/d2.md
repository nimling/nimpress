A ` ```d2 ` fence or a linked `.d2` file renders as a diagram. nimpress lays it out at build time, so a page with a diagram downloads no diagram library. The authoring reference is in [D2](/authoring/d2).

## A flow

```d2
direction: right
write: Write markdown
lint: nimpress lint {shape: diamond}
build: Build {shape: hexagon}
ship: Publish {shape: cloud}
write -> lint -> build -> ship
lint -> write: fix {style.stroke-dash: 3}
```

## Containers

```d2
cloud: Cloud {
  api: API
  queue: Jobs {shape: queue}
  db: Postgres {shape: cylinder}
  api -> queue
  api -> db
  queue -> db
}
browser: Browser
browser -> cloud.api: https
```

## A schema

```d2
direction: right
users: {
  shape: sql_table
  id: uuid {constraint: primary_key}
  email: text {constraint: unique}
  name: text
}
bookings: {
  shape: sql_table
  id: uuid {constraint: primary_key}
  user_id: uuid {constraint: foreign_key}
  starts_at: timestamptz
}
bookings.user_id -> users.id: {target-arrowhead.shape: cf-one; source-arrowhead.shape: cf-many}
```
