Every term on this page gets a dotted underline and a tooltip wherever it occurs in the prose of any other page.

Frontmatter
: The YAML block at the top of a markdown file that declares the title, the type, and every other field of the page.

Sidebar
: The navigation column built from the content tree, with one row per page and one group per folder.

Right rail
: The table of contents beside the content column, built from the H2 and H3 headings of the page.

Shell
: The header, the sidebar, the content column, and the right rail that every page renders inside.

Token
: A CSS custom property with a light and a dark value that every visual choice in nimpress goes through.

Directive
: A fenced container in markdown, opened with three colons and a name, that renders as a callout, a tab group, an action row, or a grid.

Callout
: A box beside the prose that holds side content, one of thirteen types from tip to quote.

Story
: An executable file beside a component page that mounts the component with props or a render function.

Harness
: The iframe frame the component workshop mounts a story in, with the system setup and the overlay root.

Manifest
: The build time index of every page, its route, its sidebar node, its tags, and the site wide data the runtime reads.

Gate
: The frontmatter field that moves a page out of the public bundle and behind the auth provider.

Base
: The URL prefix the whole site is served under, such as a project page path.

Changelog collection
: Many release files in one folder that collapse into one page, newest first.

Spine
: The curve on a roadmap page that carries the issues, the release markers, and the rocket.

DBML
: The database markup language a schema page or an inline fence is written in, rendered as an interactive diagram.

OpenAPI
: The specification format a reference page is rendered from, with one section per operation.
